# 🥕 당근마켓 키워드/가격 필터 매물 알리미 (Chrome Extension)

당근마켓에서 원하는 **제품명**, **가격 범위(최소~최대)**, **지역(동 단위)**을 필터링하여 실시간 매물을 조회하고, 최신순/최저가순으로 정렬하며, 백그라운드 푸시 알림을 받을 수 있는 크롬 확장 프로그램입니다.

---

## 📁 파일 구조

```
chrome_carrot_search/
├── manifest.json       # Manifest V3 확장 프로그램 설정
├── popup.html          # 확장 프로그램 팝업 UI 화면
├── popup.css           # 당근마켓 테마 스타일 시트
├── popup.js            # 매물 검색, 지역 변환, 정렬 및 알림 로직
├── background.js       # 주기적 백그라운드 확인 및 데스크톱 알림 서비스 워커
├── icons/              # 16px, 48px, 128px 당근 아이콘
└── README.md           # 사용 설명서
```

## 🚀 크롬 브라우저에 설치하는 방법 (30초 소요)

1. 크롬 브라우저를 열고 주소창에 `chrome://extensions`를 입력하여 이동합니다.
2. 우측 상단의 **`개발자 모드(Developer mode)`** 토글을 켭니다.
3. 좌측 상단의 **`압축해제된 확장 프로그램을 로드합니다 (Load unpacked)`** 버튼을 클릭합니다.
4. 아래 폴더 경로를 선택합니다:
   ```
   /Users/eo/.gemini/antigravity/scratch/chrome_carrot_search
   ```
5. 크롬 우측 상단 퍼즐 아이콘(확장 프로그램)에서 **🥕 당근마켓 키워드/가격 알리미**를 고정(Pin)합니다.

## 💡 주요 기능 및 사용법

### 1. 세부 입력 조건
* **검색할 제품명**: 예) `나이키 로말리오4`
  * *팁: '로말리오' 입력 시 판매자가 많이 사용하는 '로말레오' 키워드 매물까지 자동으로 함께 탐색합니다.*
* **가격 범위 (단위: 만원)**:
  * 예) 최소 `10` ~ 최대 `15` 입력 시 **10만 원 ~ 15만 원** 범위 매물만 필터링
  * `전체`, `~10만`, `10~15만`, `15~20만` 빠른 태그 버튼 지원
* **지역 (동 기준)**:
  * 예) `용현동` 입력 시 당근마켓 지역 API를 통해 내부 코드(`용현동-6513`)로 자동 변환하여 해당 동네 매물을 조회합니다.
  * 비워둘 경우 전국 단위로 매물을 조회합니다.

### 2. 결과 출력 형식 (정렬 옵션)
* **⏱️ 가장 최신순**: 등록 순서 기준 최신 매물 순
* **💰 가장 저렴한 순**: 낮은 가격순 정렬
* **💎 높은 가격순**: 고가 상품순 정렬
* *선택 즉시 별도 재검색 없이 화면이 실시간으로 재정렬됩니다.*

### 3. 백그라운드 자동 알림
* **'새 매물 주기적 알림 받기'**를 켜두면, 팝업을 닫아두어도 설정한 주기(5분, 15분, 30분, 1시간)마다 크롬 백그라운드에서 매물을 감지하여 **새 매물 등록 시 데스크톱 푸시 알림**을 띄워줍니다.
